FUNNGRO — TWO-PAGE WEBSITE CONCEPT

Project files
- index.html: navigation/landing page for the two audiences
- teen.html: teen-facing page
- company.html: company/brand-facing page
- style.css: responsive layout and visual system
- script.js: mobile navigation and FAQ interactions
- Funngro_SEO_Audit_Report.pdf: preliminary desk-based SEO review of the live Funngro website

Preview
1. Extract the ZIP.
2. Open index.html in a browser.
3. Use navigation to visit teen.html and company.html.
4. Test on a phone and desktop.

Scope
This is an independent concept website for an assessment. It is not the official Funngro website and is not affiliated with or endorsed by Funngro. It does not include backend services, live campaign listings, user accounts, payment processing or analytics.

Submission checklist
1. Upload the site folder to a static host (GitHub Pages, Netlify or Vercel).
2. Test the published URL on a phone and desktop.
3. Check all internal links and external calls-to-action.
4. Paste the published URL into the task's Remark field.
5. Attach the SEO audit PDF separately if attachments are supported; otherwise include a share link to the PDF in the remark.
6. Do not add invented metrics, testimonials or guarantees.
